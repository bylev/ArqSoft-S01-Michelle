# Catálogo Musical
----

# Introducción

En esta actividad, se realizó un catálogo de música con un estilo arquitectónico *Model-View-Controller* en la plataforma .NET. Este catálogo maneja álbumes de diferentes artistas, y tiene diferentes funciones como agregar un nuevo álbum y filtrar por género músical.

---

# Objetivo

Comprender el funcionamiento básico de .NET como desarrollo de Web Apps. Mediante la arquitectura de MVC. 

---

# Agregar un Nuevo Álbum

Para agregar un nuevo álbum: 
1. Haz click en el botón "Agregar álbum"
2. Completa el formulario con lo que se requiere.
3. Haz click en "Guardar álbum"
4. Automáticamente te redirige al catálogo.

---

# Ver Detalles de un álbum

1. Desde el catálogo, haz click en el bóton "Ver Detalles"
2. Se muestra toda la información del álbum.
3. Usa el botón "Volver" para regresar al catálogo.
